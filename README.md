## Install

1. Open the download link above on your phone.
2. Open the downloaded file and allow your browser or file manager to **install unknown apps** when Android asks.
3. Launch Satchel, enter your Caravan server address (e.g. `http://192.168.1.50:8420`) and sign in.

Newer builds install over older ones, and Satchel shows a ribbon when a new release is out.
Releases are built automatically from the Caravan repository; this repository holds only the release metadata.
